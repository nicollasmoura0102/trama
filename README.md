# Trama

Projeto final de DIU 2026/2 (UDESC/CEAVI). Loja de roupas desenvolvida com React e Vite.

## Como rodar

```bash
npm install
npm run dev
```

Abra `http://localhost:5173` no navegador.

Para gerar a versão de produção:

```bash
npm run build
npm run preview
```

## Principais recursos

- Tema claro e escuro com escolha persistente.
- Busca, filtros e página de produto.
- Favoritos, sacola, pedidos e avaliações salvos no LocalStorage.
- Cadastro, login e opção de manter a conta conectada.
- Fluxo de compra: início, busca, produto, sacola, checkout e conta.
- Layout responsivo e navegação mobile.

## Tecnologias

React, Vite, React Router e CSS.
